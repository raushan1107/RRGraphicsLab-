# RR Graphics Lab — OpenGL & Vulkan

Computer graphics with OpenGL and Vulkan: module-wise notes, day-by-day demos, a demo catalogue and a capstone (tactical radar display, OpenGL → Vulkan).

## What's inside

- `index.html` — lab home and module notes
- `day1-demos.html` … `day4-demos.html` — demos by day
- `catalogue.html` — demo catalogue
- `capstone.html` — capstone project

## How to use

Static site: open `index.html` in a browser (GitHub Pages can be enabled for a public link).
